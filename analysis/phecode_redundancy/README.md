# Phecode-redundancy sensitivity analysis

Read-only analysis of whether the network's clusters are driven by phecode
definitional overlap rather than pleiotropy.

Nothing here writes to production data, the precomputed network files or the
served site; everything it produces lands in `results/`.

The "Hide edges between related phecodes" toggle built on the back of this
analysis lives on the **`hierarchy-mask-toggle`** branch, which adds
`build_relations.py`, `evaluate_toggle.py` and
`results/TOGGLE_EVALUATION.md` here plus the site changes. It is unmerged
and awaiting sign-off.

## Reports

| File | What it is |
|---|---|
| `results/A0_RECON.md` | reconnaissance, baseline reproduction, and the inputs that were missing |
| `results/REPORT.md` | the sensitivity analysis (Part A) |

## Running it

```bash
# Part A. All parameters are at the top of run_analysis.py.
python3 analysis/phecode_redundancy/run_analysis.py --steps a2,a3,a5,a6
python3 -m pytest analysis/phecode_redundancy/test_phecode_relations.py -q

# Positions for the locus work (A4). Needs Bioconductor and
# SNPlocs.Hsapiens.dbSNP155.GRCh38; takes about an hour and ~10 GB.
Rscript analysis/phecode_redundancy/snp_positions.R \
        results/rsids.txt results/snp_positions.csv
```

## Files

| File | Role |
|---|---|
| `phecode_relations.py` | the tier classifier — **single source of truth** |
| `test_phecode_relations.py` | its unit tests (17, nothing skipped) |
| `network.py` | rebuilds the phenotype network the way the site does; its docstring lists the three deviations |
| `run_analysis.py` | entry point for A2–A6 |
| `snp_positions.R` | rsid → GRCh38, via SNPlocs/dbSNP155 |
| `annotate_loci.R` | nearest gene per lead SNP, TxDb + org.Hs.eg.db |

## Inputs that are not in the repo

`run_analysis.py` reads three files from outside the working tree, all
recorded with checksums in `results/provenance.json`:

- `~/Downloads/Phecode_map_v1_2_icd9_icd10cm.csv` — ICD→phecode, for T4
- `~/Downloads/phecode_definitions1.2.csv` — exclusion ranges, for T3
- `~/Desktop/phenotype_labels.pkl`

Without the definitions file the classifier returns `None` for T3 rather
than `False`, and the analysis reports the affected level as `L3_partial`.
An absent tier must not read as an absent relationship.

`results/snp_positions.csv` is regenerated by `snp_positions.R` and is
gitignored; A4 reports its locus metrics as empty if it is missing rather
than falling back to SNP counts.
